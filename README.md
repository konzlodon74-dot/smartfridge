## How it works

`main.py` holds the one-line roast as a constant, asserts it is non-blank, single-line, and at most 160 characters, then writes it as UTF-8 bytes with no trailing newline to `/output/entry.txt`, creating the output directory if needed.

## Run

```bash
python3 main.py
cat /output/entry.txt
```
